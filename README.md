# 🎡 BWA - CHATTY

BWA CHATTY adalah aplikasi mobile berbasis Flutter dengan konsep aplikasi chatting. Aplikasi ini membantu pengguna untuk terhubung, berbagi momen, serta berdiskusi dalam grup dan lingkup pertemanan secara modern dan ringan.

Aplikasi ini dibuat sebagai bagian dari portfolio mobile developer dengan fokus pada UI sosial yang dinamis, struktur chat/grup, dan pengalaman pengguna yang nyaman.

## 🧠 About The Project

BWA CHATTY dirancang sebagai aplikasi sosial sederhana dengan konsep:

> *"Stay connected, share your story, and find your circle."*

Proyek ini menampilkan halaman daftar teman dan grup (seperti pada referensi WhatsApp), dengan desain minimalis namun informatif, serta menjadi dasar untuk pengembangan aplikasi komunitas yang lebih kompleks.

## ✨ Features

- 👥 Daftar **Friends** dengan status terkini
- 👥 Daftar **Groups** dengan pesan terakhir
- 🎨 Clean & Modern UI terinspirasi dari chat apps
- 📱 Responsif untuk berbagai ukuran layar
- 🧭 Navigasi sederhana antar halaman
- ⚡ Performa ringan dengan Flutter
